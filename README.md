📊 Car Sales Performance Analysis Dashboard

🚀 Project Overview

This project analyzes 50K+ car sales records to uncover insights on revenue trends, regional performance, and product-level contribution. The goal was to enable data-driven decision-making for sales strategy and inventory planning.

🎯 Business Problem
* Which regions are underperforming?
* Which product segments drive the most revenue?
* Are there seasonal trends in sales?

🛠️ Tools & Technologies
* Power BI – Dashboard & Visualization
* DAX – KPI calculations (YoY growth, running totals)
* SQL – Data extraction and transformation
* Excel – Data cleaning

📈 Key Insights
🚗 SUV segment contributes ~45% of total revenue
📉 Certain regions consistently underperform across months
📊 Clear seasonality trends observed in monthly sales
💡 Top-performing products drive majority revenue contribution
